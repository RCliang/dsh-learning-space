# quiz — 出题规范

任何需要"做题"的场合：probe 阶段定位水平、教学中的节点确认、错题复习。配合 teach skill 使用。

## 聊天内固定格式

```
**第 2 / 5 题 · 离散采样**

以采样率 $f_s$ 对信号采样，能无失真恢复的最高信号频率是？

A. $f_s$
B. $\dfrac{f_s}{2}$
C. $2f_s$
D. $\dfrac{f_s}{4}$
```

用户答一个字母（如 `B`），立刻反馈，然后再下一题：

```
✅ 正确 —— 奈奎斯特定理：恢复需要每个周期至少两个采样点，所以上限是采样率的一半。
```

## 规则

1. **选项裸列**：任何选项都不带"为什么"，所有推理放在反馈里，答题后才出现。数字选项尤其注意，给正确项加理由等于标星号。
2. **干扰项靠构造**：先写正确断言，再各取一个具体误解（无心之失 / 孤立记忆 / 概念混淆），问"持这个误解的人会怎么答"，以同样骨架写出来。
3. **每个干扰项都要有诊断价值**：是他可能真犯的错，但在预期解读上明确错。不玩文字游戏。
4. **不做非对称加粗/强调**：要么都不强调，要么每项强调平行的术语。
5. **即时反馈**：答对答错都要给一句"为什么"；答错时同时指出这暴露的是哪类误解（要进错题本的依据）。
6. **一次一题**，答完再出下一题；probe 阶段按二分策略跳难度（对→大幅加难，错→收窄定性）。
7. 数学记号一律 LaTeX，与正文渲染一致。
8. **边界探测逻辑**（probe 专用）：全对不算会，继续加难度直到出错；单个错不急于定性，在它周围再探一两题区分误解类型。

## 无对错答案的问题不用 quiz

偏好、方向、"你接下来想学什么"这类问题用 ask_user_question，不要伪装成选择题。
